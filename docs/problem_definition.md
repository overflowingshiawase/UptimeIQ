# UptimeIQ 升級版 — 問題定義

## 一句話定位
UptimeIQ 原本是給廠長看的被動式儀表板，這次升級成會自己判斷、自己通知、自己整理紀錄的維運助手——診斷邏輯來自本人在產線上實際驗證過的規則，不是黑盒子AI預測。

## 這次升級做什麼（只有兩項）
1. **異常自動診斷與推播**：系統定期檢查機台保養間隔，依規則算出風險分數，超過門檻時自動生成診斷說明並推播給負責人
2. **班別交接自動結構化**：操作員輸入簡短交接重點文字，系統自動整理成結構化紀錄，並標記完整度不足的交接

## 這次升級不做什麼
詳見 `future_work.md`。原則：任何超出上述兩項的功能，一律先記錄進Future Work，不在這次實作範圍內。

## 目標使用者
- 廠長/主管：即時收到異常診斷推播，不用自己盯儀表板
- 班別操作員：交接時只需打幾句重點，不用自己整理成正式格式
- 下一班接手人員：能看到結構化、完整度有把關的交接紀錄

## 成功標準
- 兩條n8n流程能穩定手動觸發並正確寫入資料庫
- 風險分數與完整度分數的計算邏輯能清楚說明依據，而非「AI覺得」
- README能誠實呈現v1→v2的演進過程與量化前後對比
